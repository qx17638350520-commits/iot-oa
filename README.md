# 现代物流 · 教学实训平台

独立现代物流教学系统，与物联网系统分别部署、分别保存数据。面向现代物流管理专业群建设需求，提供可运行教学 MVP，不宣称完整招标参数验收、真实设备接入或生产环境能力。

## 启动

安装 Python 3，运行 `python3 server.py`（Windows 也可双击 start.bat，macOS/Linux 执行 sh start.sh），访问 http://127.0.0.1:8770 。也可将 dist 部署到任意支持静态文件的 HTTPS 服务。请通过 HTTP/HTTPS 运行，不直接双击 HTML。

所有数据保存在当前浏览器当前域名的 localStorage，命名空间 logistics_v1_；考试草稿为 logistics-exam-draft-v1。独立私有站点用于控制访问，但教师/学生视图不是多租户权限系统。不同浏览器、不同访问域名之间不自动同步，同一浏览器请保持单个编辑标签页。清理浏览器数据会删除记录。未连接真实车辆、传感器、无人机或学校账号。

## 首次演示：完整物流闭环

1. 工作台点击“载入教学样例”。样例为虚构的冷藏鲜果、乳制品、两台教学车辆。
2. 仓储与库存：登记入库。已有 SKU 只累加数量，不覆盖原库位和环境要求；数量必须为正整数。
3. 运输调度：选择有空闲容量的冷藏车，创建 20 箱、30 km、60 min 任务。计划立即预留库存，但在库数量尚未扣减。重复占用车辆、超库存和超载会被阻止。
4. 点击发运：在库库存扣减并留下出库流水，任务转为运输中；重复发运会被阻止。
5. 冷链监控：提交模拟温度、湿度、行进距离、横向偏移和时间。分别尝试温度 12°C、湿度 95%、偏移 4 km、设备离线；超过任务时效产生运输超时告警。重复异常不会反复堆叠未恢复的同类事件。模拟时钟对所有运行中任务生效。
6. 告警处置：填写确认备注。确认表示已阅读，正常采样才表示相应阈值/偏航/离线事件恢复。运输超时保留历史记录。
7. 到达规划终点且偏移不大于 2 km 后，点击签收填写教学签收代号。交付保留记录，不重复扣减库存。
8. 实训证据与报告：填写观察结论并保存当前台账、运单、遥测、告警的不可变快照，可导出 JSON。

## 教学和技术模块

- 题库与考核：1500 道内置主问题（既有280道 + 第二阶段1220道原创 AI 草稿）、六种题型、题库 JSON 导入、结构化组合题/自定义字段与评分量表、按班级/学员分配、开放/截止时间、限时作答、客观题评分、逐项主观审核和成绩。组合题小题不重复计数；教师审核尚未完成。
- 教学管理：多班级名单、学员归属、班级工作区、教学安排日历；不创建真实登录账号。
- 基础课程：6 门课程、18 节文字微课、6 项引导实验与报告记录。
- 综合案例：智慧校园、智慧仓储、智慧运输、口罩标注数据准备、智慧温室。案例包含任务步骤与验收产物，不伪造项目照片或检测认证。
- 数字孪生：2D/等距 3D 场景、组件布局、属性、阈值、开关/强度控制与模拟采样。支持18类组件、按钮/门窗/窗帘/光照与风机控制、虚拟指纹事件及商超购物车/结算/库存/票据闭环。虚拟身份事件不是生物识别，摄像头不是实时视频流；设备、交易及账户均为本地教学仿真。
- 视觉检测：同源 TensorFlow.js 4.22.0 + COCO-SSD 2.2.3 lite_mobilenet_v2，真实浏览器推理，80 个 COCO 通用类别，矩形结果可人工修改；支持关键点、标签层级与 JSON 导出。不是工业专用、口罩专用、人脸身份识别模型。第三方许可证及来源在 dist/static/vendor/vision/。
- 知识数据：JSONL 质量检查、去重、训练/验证划分、显式关系句规则提取、三元组查询与人工复核、训练参数导出。提供一次已完成的离线 CPU LoRA 微调证据；网页不启动微调作业，生成质量尚不可靠。
- 低空物流、消费 CSV 分析、线路/RFID 实训、真实轻量神经网络实验：见各工作台内的操作说明和边界提示。

## 数据导出

物流各页面顶部“导出作业数据”导出物流台账、任务、告警和报告；报告可独立导出证据。基础教学管理页的备份只包含题库、考试、孪生、视觉、知识和基础课程模块。其他扩展实验使用各自页面的导出按钮。静态源码包不包含浏览器业务数据。导出文件可能含自行录入的学员或业务资料，请妥善保管。

## 验证

运行 `sh verify.sh`。测试包含库存守恒/预留/取消/重复发运、容量和车辆占用、五类告警、恢复、签收、证据快照，页面真实事件处理器在显式 mock DOM 下的业务闭环、失败保存回滚/重试，以及复用题库、持久化、课程、标注和孪生生命周期回归。模型文件完整性与 80 类映射已验证。

当前云环境缺少可用的受支持浏览器 QA 路径。没有使用用户电脑，没有声称真实浏览器布局验收；没有伪造软件截图或视频。UI 采用响应式 CSS，但视觉、移动端触控、下载体验和浏览器实际推理仍需真实浏览器验收。

## 五项演示对照与已知边界

1. 智能视觉：可实际运行 COCO 通用目标检测、矩形框修订、手工关键点、分类层级和 JSON 导出。没有已训练工业零件/管接口专项模型，不能把手工补标当模型自动识别。
2. 神经网络：数值多分类网络执行真实梯度训练并显示真实曲线；图像迁移学习模块采用已有 MobileNetV2 预训练骨干与新分类头。专用工业数据集与正式准确率指标需另行采集、审核和测定。
3. 领域大模型与知识图谱：JSONL 校验、拆分、参数准备和规则三元组提取可操作；没有已微调的领域大模型服务，没有伪造训练日志或损失曲线。
4. 技术实训：端子接线编辑/诊断/导入导出、逻辑协议校验、RFID 去重入库和简化认证/存储/碰撞教学可操作；没有真实电气、射频或预配置 MQTT 服务器连接，不声称已完成实物传感器联动。应用开发页提供真实 MQTT 3.1.1 over WSS 协议客户端，但须用户主动指定授权匿名教学 Broker 并确认连接；代码协议测试通过，真实服务器端到端连接未测试。
5. 考核：1500 道内置主问题（待教师审核）与导入、组卷、实际评分和答卷记录；完整 1500 道审定题库仍是缺口，教师学生角色为本地工作流。

## 15 分钟内的软件演示顺序建议（不是已录制视频）

- 0:00–2:30：创建货品→运输计划→发运→模拟温度超限→告警备注→到达签收。
- 2:30–5:00：端子画布故意接错/纠正，协议参数冲突，RFID 重复扫描与内存操作。
- 5:00–7:30：上传授权图片→通用检测→手工关键点/分类层级→导出 JSON。
- 7:30–10:30：数值样本真实训练→曲线/混淆矩阵→图像迁移学习结构与已保存真实结果。
- 10:30–12:00：问答 JSONL 校验→规则关系提取→图谱复核→训练配置导出；明确领域大模型训练未连接。
- 12:00–14:30：组卷→学生答题→客观评分/主观审核→保存报告与证据。

录制需要真实浏览器操作和同步讲解。本交付没有生成假录屏，也不以该顺序建议代替采购验收视频。

应用开发实验台可离线运行 JSON 温湿度校验→阈值控制规则→虚拟元件反馈。可选 WSS 客户端支持匿名连接、QoS0 订阅/发布和QoS1接收，切页断开。无默认服务器，不保存端点或凭据，发布需页面确认；仅使用授权教学 Broker，不能作为生产设备控制系统。Python示例仅供设备端参考，本页不执行Python。协议依据：https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html

## 图像迁移学习验证

本地同源 COCO-SSD MobileNetV2 骨干提取真实1280维特征，冻结骨干后训练新的softmax分类头，界面显示结构、逐轮真实损失、分层留出测试、混淆矩阵和单图预测。训练图片仅在页面内存，分类头/配置/结果可保存与导出。已用18张明确标记的合成图案完成实际CPU验证，149组骨干权重哈希不变，loss1.2144降至0.4774，留出测试3/6正确。这证明流程执行，不证明工业模型精度。验证报告为 transfer-verification.json。实际用户应使用授权且足够多样的工业图片重新训练并独立评估。

## 已完成离线 LoRA 实验证据
知识面板提供 Qwen2.5-0.5B-Instruct（Apache-2.0）CPU LoRA 完成记录、逐步原始日志、数据来源、固定版本、训练配置、6条留出损失与3组原样生成对照，并可下载真实运行器和适配器。24条原创合成训练样本、48步；留出损失从4.13369降至3.37735，不等于准确率提升，生成结果仍不可靠且存在退化。网页不启动或伪装在线训练，不连接真实设备。
