# 物联工坊 · IoT Studio

可运行的中文物联网教学与实训原型。包含课程、实验、数字孪生、考核、AI 视觉、知识数据与教学管理；不是静态展示页。

## 本机启动

需要 Python 3.10+。无需安装后端依赖。

    python server.py

打开 http://127.0.0.1:8765 。Windows 可双击 start.bat；Linux/macOS 可运行 ./start.sh。默认仅监听本机地址。结束时 Ctrl+C。

本地版通过 data/platform.sqlite3 保存工作区，首次启动自动创建。网页托管版使用当前浏览器的 localStorage；更换浏览器/设备或清理站点数据不会自动保留记录。管理页可导出与恢复完整备份。该原型不提供生产级账号认证、多租户权限隔离或远程设备同步，不应把本地服务直接暴露公网。

## 可操作功能

### 课程与实验

6 门课程、18 节文字微课，每节包含知识讲解、实践任务、笔记和真实检查题。完成状态由阅读勾选、实践记录和正确答题决定。6 个实验任务提供步骤、观察记录、依据、反思、客观检查题、报告提交/修订与导出。MQTT 实验还提供真实主题过滤匹配器。实验提交为当前工作区记录，不会向真实教师发送消息；步骤由学习者自行确认。

### 数字孪生

建筑双层空间、家居五区、商超货架/冷柜/收银三个独立场景；18 类组件，分别预设 19/13/12 个设备。支持 2D/3D 几何投影、旋转/缩放/楼层、拖拽/键盘编辑、设备属性、阈值、告警与事件、运行曲线、环境情境、控制联动、保存/恢复和 JSON/CSV 导出；切换工作台时等待未保存编辑写入，失败时留在原编辑器。独立提供温度、湿度、光照、可燃气体 %LEL、电压 V、电流 A、功率 kW 与按采样时间累积的电能 kWh；提供灯光、窗帘、门锁/门磁、报警输出和指纹允许/拒绝演练。指纹只验证演示凭据，不采集真实生物信息。商超购物篮按件/克计算价格、净重，支持模拟余额/现金结算、找零与逐项收据；金额使用整数分计算，无真实支付。所有读数与控制均为本地仿真，未连接物理设备。

### 题库与考核

1500 道内置主问题（既有280道 + 第二阶段1220道原创 AI 草稿，教师审核尚未完成），涵盖单选、多选、判断、填空、组合和自定义题型。支持题目新建/编辑、JSON 批量导入导出、教师选题组卷与发布、按班级/学员分配及开放/截止时间、学生本地档案筛选与限时作答/恢复、客观题自动评分、主观题人工评分、逐题解析、知识领域表现及成绩导出。组合题可配置独立小题和权重，自动汇总客观小题并保留主观小题待评分；自定义题可配置作答字段与加权评分标准，逐标准人工评分。截止时间限制答题期限；草稿与成绩绑定本地档案。旧版自由文本组合/自定义题仍按人工评分处理。演示角色切换不是权限认证。组合题的小题不重复计入1500道主问题；详见最新质量清单。

### AI 视觉与工业标注

真实 COCO-SSD 2.2.3 / lite_mobilenet_v2 通用目标检测，TensorFlow.js 4.22.0 在浏览器本地执行。全部运行库、model.json 和 5 个权重分片随项目同源部署，约 20 MB，运行时无需访问 Google/CDN。图片不发送至外部推理 API。

上传包含人、车辆、瓶子、椅子等模型支持类别的真实照片，可自动执行识别，调节阈值，编辑框坐标/类别并人工复核。失败/无结果会显示真实状态，不生成替代框。COCO 的 80 类不包含工业泵、电机、仪表等专用细分类别；这些内容仍需人工标签、矩形框、关键点和层级归属。支持撤销、保存、LabelMe 兼容 JSON 导出，包含原图、置信度、模型来源、修订与复核状态。默认工业示例是离线绘图，用于人工标注练习，不是 AI 检测结果。

许可与官方来源见 static/vendor/vision/LICENSE 和 PROVENANCE.json。

### 图像分类迁移学习

使用同源冻结 MobileNetV2 特征提取器（1280维）与新建分类头，实际在浏览器执行训练。用户提供每类至少5张物品图像，进行分层训练/留出划分、优化、混淆矩阵评估、新图预测与分类头导出/恢复。训练图片仅在内存中，保存的是类别、配置、分类头和真实评估结果。默认未训练任何工业类别。此流程是图像分类，不是目标框/关键点检测，也不是大语言模型微调；实际性能取决于提供的数据。CPU回归使用合成颜色形状图像，仅用于验证计算流程，结果不代表工业识别精度。

### 知识数据

JSONL 导入/校验/搜索/导出；明确短句规则提取三元组；关系人工添加、审核、查询，图谱节点详情与 JSON 导出；训练参数保存/导出；固定随机种子下的训练/验证集划分。此模块不启动大模型微调，不提供虚构的训练进度或损失指标。

### 教学与数据管理

多班级创建、学员录入/转班编辑/移除/筛选/导出，教学设置，工作区数据清单，完整 JSON 备份及校验恢复。恢复前确认覆盖范围，校验结构后写入；发生保存失败时尝试回滚。备份可能包含图片、名单和答卷，请妥善保管。进行中的考试草稿不包含在完整备份内。

## 建议演示路径

1. 课程中心：阅读微课、完成任务记录与随堂题。
2. 实验中心：打开任务书，跳转工作台实践，记录发现。
3. 孪生：切换场景/楼层，编辑组件，运行仿真情境，查看曲线和告警，保存/导出。
4. 视觉：上传真实通用物体照片，等待真实识别，修改框并复核；用工业绘图练习关键点与层级。
5. 知识：校验 JSONL，提取/查询/审核关系，导出划分和训练配置。
6. 考核：教师组卷、学生作答、查看评分与解析。
7. 管理：导出完整工作区备份。

仍未实现：真实物联网硬件接入，工业专用目标/关键点预训练模型与可靠领域大语言模型能力，OCR/手势/分割/GAN/ONNX 完整实验体系，生产级身份权限，以及经过教师审定的采购题库。本项目不声明采购技术指标全面达成。

## 已完成离线 LoRA 实验证据
知识面板提供 Qwen2.5-0.5B-Instruct（Apache-2.0）CPU LoRA 完成记录、逐步原始日志、数据来源、固定版本、训练配置、6条留出损失与3组原样生成对照，并可下载真实运行器和适配器。24条原创合成训练样本、48步；留出损失从4.13369降至3.37735，不等于准确率提升，生成结果仍不可靠且存在退化。网页不启动或伪装在线训练，不连接真实设备。
